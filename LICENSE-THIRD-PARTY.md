## Larian Studios: Baldur's Gate 3

Raphael Joins the Party is an unofficial, fan-made modification for Baldur's Gate 3. It is not affiliated with or
endorsed by Larian Studios, and it is made under Larian's
[Baldur's Gate 3 Fan Content Terms](https://baldursgate3.game/modding-terms).

- **Raphael's voice.** Every spoken line in the mod is one of Raphael's original recordings from the base game,
  performed by **Andrew Wincott**. The mod ships **no audio files**: it points the game's own dialogue system at
  recordings already in the game.
- **Characters and story.** Raphael, the House of Hope and every other Baldur's Gate 3 character, place and story
  element belong to Larian Studios.
- **Game data.** His camp conversation's timeline is an unmodified copy of one of the game's own camp timelines, and
  its scene file is derived from that timeline's scene. The mod's other dialog and character data are built on the
  structure of the game's own files. All rights to Baldur's Gate 3 remain with Larian Studios.

## BG3 Script Extender: optional dependency (not included)

By [Norbyte](https://github.com/Norbyte/bg3se). Not bundled; users install it themselves. All rights remain with its
author.

## Mod Configuration Menu (BG3MCM): optional dependency (not included)

By AtilioA and contributors (NexusMods mod 9162). Not bundled; users install it themselves. The mod ships an MCM
*blueprint* (a JSON description of its own settings, written by the mod's author) that MCM reads; it contains no MCM
code. All rights to MCM remain with its authors.

## Summary

The mod bundles no third-party binaries, tools or audio. Its optional dependencies are installed separately by the
user.
